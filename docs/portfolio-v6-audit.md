# Portfolio v6 visual and accessibility audit

The human-centered redesign replaces screenshot-like hero and flagship previews with legible evidence summaries whose metrics, destinations and evidence boundaries remain readable at portfolio scale. Gray Swan uses a dated vector summary while the evidence page preserves the original screenshot metadata, cryptographic hash, live profile, previous Perma.cc snapshot and WACZ record. Entropy for Life uses a contribution overview that separates 55+ video projects from four co-authored articles and states that roles vary by output.

Final acceptance checks cover desktop, tablet and 390 px mobile rendering; light and dark themes; JavaScript-disabled output; horizontal overflow; generated HTML mirrors; four exact two-page application PDFs; the master CV PDF; link-label accessibility; color contrast; and production-like Lighthouse audits.

The Gray Swan live profile is the primary destination and the dated evidence page is the verification record; the earlier Perma.cc capture is retained as a historical fallback. Wikimedia Commons links from the homepage point to a selected self-authored autism-genetics visualization rather than the complete upload history.
